# ArsGPT 🇮🇱

צ'אטבוט AI עם אישיות של ערס ישראלי מצחיק וחברותי. אתר בעברית (RTL), רספונסיבי, Dark/Light mode, היסטוריית שיחות מקומית, שאלות מהירות ומצב הדגמה ללא מפתח.

## התחלה מהירה — GitHub Pages (הדגמה)

1. GitHub → Settings → Pages.
2. בחר **Deploy from a branch**, ענף `main` ותיקייה `/(root)`.
3. האתר יהיה בכתובת `https://alonweizzz.github.io/ArsGPT/` אחרי ש-GitHub יסיים לפרסם.
4. GitHub Pages מאפשר **מצב הדגמה בלבד**. אין בו שרת להרצת AI אמיתי.

## AI אמיתי באמצעות Vercel

1. היכנס ל-[Vercel](https://vercel.com) וייבא את הריפוזיטורי.
2. בהגדרות הפרויקט, Environment Variables, הוסף `OPENAI_API_KEY` עם מפתח סודי לחשבון API שלך. אפשר להוסיף `OPENAI_MODEL` (ברירת מחדל `gpt-4o-mini`).
3. בצע Deploy. אל תשים מפתח API בקובץ Javascript של הדפדפן, ב-HTML או בריפוזיטורי.
4. באתר שהופעל ב-Vercel לחץ על ⚙ והזן כתובת `https://YOUR-DOMAIN.vercel.app/api/chat` ושמור.
5. כעת האתר ישלח שיחות לשרת, והשרת יפנה אל OpenAI. שימוש ב-API עשוי להיות כרוך בתשלום.

**חשוב לפני פרסום רחב:** הוסף אימות משתמשים, rate limiting ומכסת שימוש כדי למנוע ניצול לרעה ועלויות API. נקודת הקצה בדוגמה פתוחה לכל מי שמכיר את כתובתה; זו גרסת MVP ולא שרת מוקשח לפרודקשן. היסטוריית השיחות נשמרת בדפדפן המשתמש בלבד.

## קבצים
- `index.html`: מבנה האתר
- `style.css`: עיצוב
- `app.js`: UI, שיחות, והדגמה
- `api/chat.js`: פונקציית שרת ל-Vercel
- `vercel.json`: תצורת Vercel

הקוד בנוי ללא ספריות פרונטאנד כך שגם מתחילים יכולים לערוך אותו בקלות.
